# קונסול ניהול

כלי מקומי לניהול כל המוסכים בכל הסביבות. רץ רק על המחשב שלך, לא נבנה ולא נפרס.

```bash
npm run admin
```

נפתח בכתובת:

```
http://127.0.0.1:4180
```

## הלשוניות

| לשונית | מה יש בה |
|---|---|
| מוסכים | כל המוסכים בייצור, בבדיקות ובמקומית, עם מנהלים, חשבוניות, סליקה והנהלת חשבונות |
| מוסך חדש | טופס קליטה מלא: מוסך, נייר מכתבים, מנהל ראשון, iCount, הנהלת חשבונות ופלאקארד |
| מיגרציות | מה הוחל בכל סביבה, מול הענף שלה ומול הקבצים אצלך |
| פונקציות | מה פרוס בכל סביבה, והשוואה בייט מול בייט מול הענף |
| מובייל | הבילד האחרון לכל פלטפורמה ופרופיל, וכמה שינויים במובייל עוד לא נכנסו אליו. קריאה בלבד: הבנייה נשארת ב־`release.sh` |

## מה צריך כדי שיעבוד

| מה | למה |
|---|---|
| `.env.production.local` | ייצור |
| `.env.local` | בדיקות |
| `npx supabase start` | הסביבה המקומית |
| `npx supabase login` | מיגרציות ופונקציות בבדיקות ובייצור |
| `npx eas-cli login` | לשונית המובייל |
| `git fetch origin` | השוואה לענפים `staging` ו־`main` |
| Node 22.18 ומעלה | הקוד המשותף כתוב ב־TypeScript ורץ ישירות ב־Node, בלי שלב בנייה |

## איך זה בנוי

```
packages/ops/src/        הלוגיקה, משותפת לקונסול ולסקריפטים
  types.ts               כל הטיפוסים שעוברים בין השרת לדף, מוגדרים פעם אחת
  onboarding/rules.ts    כללי הבדיקה של הטופס, רצים גם בדף וגם בשרת
  onboarding/*.ts        הכתיבות: מוסך, משתמש, חשבוניות, סליקה
admin/server/api.ts      צד השרת: נתיבים דקים שקוראים ל־ops. רק הוא מחזיק מפתחות
admin/src/
  components/            קומפוננטות כלליות של הקונסול, ובנוסף הקומפוננטות של האפליקציה (app.ts)
  features/<אזור>/       דף לכל לשונית, עם הלוגיקה הטהורה שלו ובדיקות
  i18n/he.json           כל הטקסטים, תחת console.*
```

- הדף משתמש בקומפוננטות של האפליקציה עצמה (כפתורים, שדות, טבלה, לשוניות) ובעיצוב שלה. הן מיובאות תיקייה־תיקייה, דרך `admin/src/components/app.ts`.
- הטקסטים נמצאים בקובץ תרגום כמו באפליקציה, ובדיקה אוטומטית מוודאת שכל מפתח קיים.
- הסקריפטים `onboard-garage`, `connect-billing`, `connect-payments`, `set-bookkeeping-software`, `functions-status`, `functions-drift` ו־`mobile-status` קוראים לאותן פונקציות ב־`packages/ops`. שינוי שם משפיע על שניהם.

## הגנות

- השרת מאזין רק ל־`127.0.0.1`. בקשה עם שם מארח או מקור זר נדחית.
- כתיבה (הטופס) דורשת כותרת שרק הדף של הקונסול שולח, והקלדה של שם הסביבה.
- השרת בודק את הטופס שוב, בלי קשר למה שהדף בדק.
- קבצי סביבה וקבצי לקוחות לא נגישים לדף.
- הבנייה של האפליקציה, וכך גם Netlify, לא כוללת את התיקייה הזו.
- קריאת המיגרציות לא משנה את הקישור של ה־CLI במאגר.
